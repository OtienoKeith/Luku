# COCO-SSD model

The bundled `ssdlite_mobilenet_v2` TensorFlow.js model is downloaded from the
official TensorFlow.js models storage and is used only by the local Luku backend
to reject unsuitable shopper photos before a paid YouCam generation request.

- Source: https://storage.googleapis.com/tfjs-models/savedmodel/ssdlite_mobilenet_v2/model.json
- Project: https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd
